# Background artwork

- `cave.webp`: portrait anime cave sanctuary, luminous turquoise stream, indigo rock arches, bioluminescent crystals, lavender depth, painterly atmosphere and a dark uncluttered center. No people, text, interface or logos.
- `forest.webp`: portrait photorealistic alpine forest at blue hour, distant mountains, reflective lake, faint aurora, muted blue and emerald colors, dark quiet center. No people, text, logos or interface.
- `cyberpunk.webp`: portrait photorealistic futuristic city inspired by Cyberpunk 2077, brutalist megabuildings, pipes, elevated roads, electric-yellow panels, cyan and red reflections on wet asphalt, smoky haze, dark center. No people, text, readable signs, interface or logos.

These are the production prompt descriptions. Each image is stored at 800 × 1200 pixels in WebP format. Image opacity is independent from the widget background opacity. Choose **No image** to disable the artwork without changing the theme.
